# newsletter-english-agent

매일 받는 영어 뉴스레터를 에이전트가 읽고 골라서, 요약과 실전 표현으로 정리하고 복습까지 이어주는 개인 학습 에이전트.

## 왜 만드나

개발·시사 영어 뉴스레터를 구독하고 있지만, 읽고 끝나거나(별도 기록 X) 읽지 않은 채 쌓이기만 해서 표현이 남지 않는다.
이 에이전트는 뉴스레터를 "읽을거리"에서 "매일 10분짜리 학습 재료"로 바꾼다. 또한, '나중에 읽어야지'라며 메일함에 쌓여가는 리스트를 정리한다.

영어 목표:
- 해외 공고 지원과 영어 면접
- 개발 문서를 더 빨리 읽기
- 실제 비즈니스 상황에서 쓰는 용어 익히기

## 목표

**학습**
- 아침 10분 안에 요약과 표현을 소화한다
- 간격 반복으로 복습한다

**기술**
- 프레임워크 없이 에이전트 루프를 직접 구현한다
- 고정 로직으로 처리할 부분과 LLM이 판단할 부분을 나누는 기준을 세운다
- 비용·시간·판단 정확도를 측정한다
- 이후 다른 서비스의 운영 도구로 옮길 수 있는 구조로 만든다

## 성공 기준

- [ ] 4주 동안 매일 자동 실행되고, 빠진 날이 0건
- [ ] 주별 저장 표현 수와 복습 정답률 추이를 기록
- [ ] 메일 1통당 비용·시간, 모델을 나누기 전후 비교
- [ ] 주 1회 샘플 10건으로 에이전트 판단(광고 거르기, 본문 읽기 여부) 점검
